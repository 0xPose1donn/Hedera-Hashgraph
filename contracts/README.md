# Hedera NFT Marketplace

NFT marketplace built on Hedera using HTS precompile (0x167).

## Features
- HTS NFT listing (single & batch serials)
- cryptoTransfer-based NFT movement
- SDK-based approvals
- Royalty support

## Flow
1. Admin associates token to marketplace
2. User approves NFT serials
3. User lists NFTs
4. Contract transfers NFTs via cryptoTransfer

## Tech
- Solidity
- Hedera Token Service
- Hashgraph JS SDK
- HashPack wallet
